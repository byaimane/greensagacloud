# OUAGX — Cozy Farming RPG & Admin Studio (v2.5)

A 2D cozy Farming RPG inspired by **Happy Farm** and **Stardew Valley**, built with React, TypeScript, Vite, and HTML5 Canvas — featuring **English, Français & العربية (RTL)**, a full **Home Landing Page with Copyright**, **10 RPG Farmer Levels**, a **Developed Homestead**, a **Multiplayer Valley Map & Farmers' Plaza**, and a full **Admin Control Center**.

## Features
- **Admin Dashboard (`🛡️ Admin` / Key `P`)**:
  - **Overview & Live Controls**: KPI stats, instant Gold/Level/Weather/Stamina/All-Plots controls, Global Announcement ticker, and Maintenance notice toggle.
  - **Ads Manager**: Create, pause, and track live ad campaigns across the Landing Page Banner, In-Game HUD Sponsor Pill, and Maya's Market Promo Banner.
  - **Users Manager**: Manage player roles (`Admin`, `VIP`, `Player`), status (`Active`, `Muted`, `Banned`), gift Gold/Levels, and live-sync with the active player.
  - **Levels & Economy**: Real-time sliders for XP Multiplier, Crop Growth Speed, and Harvest Sell Multiplier, plus editable Level 1–10 XP and sell-bonus overrides.
  - **Plugins Manager**: Hot-toggle live plugins (*Auto-Harvest Magnet*, *Live Valley Mini-Map Radar*, *Double Gold Festival*, *FPS & Coords Telemetry*, *Cozy Chat Moderator*, *VIP Starter Pack*) and install custom plugins.
  - **Themes & Branding**: Live-switch 5 canvas + UI themes (*Emerald Valley*, *Autumn Harvest*, *Sakura Blossom*, *Winter Frost*, *Midnight Neon*) and customize Brand Name & Copyright notice.
  - **Maps & World**: Activate Valley Map presets, create custom map realms, and add/remove Multiplayer Neighbor Farm pins.
  - **System Backup**: Export & Import Admin JSON configuration.
- **Home Landing Page + Multi-Language (EN / FR / العربية)**: Full RTL Arabic support, feature highlights, Levels 1–10 roadmap, Multiplayer showcase, and copyright footer.
- **Developed Farm**: 8 crops, up to 72 farm plots, Automated Sprinklers, Orchard Fruit Trees, Artisan Windmill (Flour, Aged Cheese, Ruby Jam), Farmhouse Upgrades, and Chickens/Cows/Sheep.
- **Multiplayer Valley Map & Farmers' Plaza**: Fast-travel, live multi-tab sync via Room Codes (`BroadcastChannel`), live Valley Chat, and Happy Farm–style Neighbor Farm visits.

## Running Locally
```bash
npm install
npm run dev
```
